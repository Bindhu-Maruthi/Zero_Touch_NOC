# ZeroTouch XAI – Network Operations Center

ZeroTouch XAI is an AI-powered Network Operations Center (NOC) application built with Python and Streamlit. It 
combines real-time monitoring, anomaly detection, incident management, and explainable AI to help identify and 
understand network-related incidents.

## Features

- Real-time network monitoring
- AI-based anomaly detection
- Incident detection and management
- Explainable AI for model predictions
- Logging and incident tracking
- Streamlit-based interactive dashboard

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Matplotlib
- NumPy
- Pandas
- Explainable AI (XAI)
